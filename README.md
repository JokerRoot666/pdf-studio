# PDF Студия — веб-версия

Мини-редактор PDF, который работает прямо в браузере: открытие и просмотр, работа со
страницами, подписи и наложение текстового слоя на сканы.

**Открыть: https://jokerroot666.github.io/pdf-studio/**

Репозиторий содержит только собранную версию (`dist`) — она публикуется через GitHub Pages.
Исходники приложения живут отдельно.

## Возможности

- **Открытие / просмотр PDF** — через «Открыть» или перетаскиванием файла в окно.
  Навигация по страницам, зум, миниатюры.
- **Редактирование страниц** — перетаскивание миниатюр для смены порядка, удаление,
  поворот на 90°, дублирование.
- **Подписи** — загрузка PNG с прозрачным фоном, установка кликом по странице,
  перемещение и масштабирование, несколько подписей на странице
  (хранятся в профиле браузера).
- **Импорт / экспорт** — открытие PDF, создание PDF из картинок (PNG/JPG), сохранение PDF,
  экспорт страниц в PNG.
- **Несколько файлов** — вкладки с документами, у каждого своя история правок.
- **Undo / Redo** — отмена и повтор правок.
- **Распознавание текста (OCR)** — для страниц, где нет извлекаемого текста (сканов),
  распознавание запускается автоматически, результат кладётся на страницу как текстовый слой.
  Работает офлайн, без внешних сервисов.
- **Регистрация «по умолчанию»** — в настольной сборке кнопка регистрирует ассоциацию с `.pdf`.

## OCR — как устроено

Распознавание выполняется целиком в браузере, никакие данные никуда не отправляются.

| Компонент | Что используется |
|---|---|
| Детекция строк | PP-OCR `det.onnx` (~4.7 МБ) |
| Распознавание | PP-OCR `cyrillic_rec.onnx` (~9 МБ), словарь `cyrillic_dict.txt` |
| Исполнение | `onnxruntime-web`, WebAssembly, один поток |

Модели лежат в каталоге `ocr/` и загружаются по относительным путям. Однопоточный режим
выбран намеренно: он не требует `SharedArrayBuffer` и заголовков COOP/COEP, поэтому
страница работает на обычном статическом хостинге вроде GitHub Pages.

Раньше в проекте использовался Tesseract.js — он удалён вместе с `tessdata` и wasm-файлами,
около 25 МБ в репозитории больше не нужно.

## Ограничения

- Для страниц с уже существующим текстовым слоем OCR не запускается — текст берётся из PDF.
- Очень мелкий текст на плотных сканах распознаётся хуже: рендер страницы ограничен по
  длинной стороне для скорости.
- Настольные функции (открытие файла из проводника, регистрация по умолчанию) в браузере
  недоступны.

## Локальный запуск

Каталог статический, достаточно любого http-сервера — открывать `index.html` через
`file://` нельзя, браузер заблокирует загрузку wasm и моделей.

```bash
npx serve .
# или
python -m http.server 8000
```

## Обновление сборки

1. Собрать приложение: `pnpm build` (каталог `dist`).
2. Скопировать содержимое `dist` в корень этого репозитория, сохранив `.nojekyll`.
3. Закоммитить и запушить в ветку `main` — GitHub Pages пересоберёт страницу автоматически.

## Стек

Vite, React, TypeScript; `pdfjs-dist` для рендера, `pdf-lib` для сборки PDF,
`onnxruntime-web` и `@gutenye/ocr-browser` для распознавания.
